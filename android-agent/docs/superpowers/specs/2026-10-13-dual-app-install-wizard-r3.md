# R3.0 双应用安装引导规格

目标：把 R2 的一个入口升级为按安装状态自动分步办理的简单向导，让客户不必查找 Clash 安装包，也能从同一助手进入官方 ChatGPT 安装流程。

## 已确认的供给约束
- 仅有用户提交的 Clash Meta ARM64 2.11.30 完整 APK，可作为内置资产，哈希保持不变。
- 没有用户提交的官方 ChatGPT APK；OpenAI 的公开官方安卓分发入口是 Google Play；不能把非官方镜像包冒充 OpenAI 直接提供的资源。
- 提供可选的本机 APK 导入路径，校验包名与 OpenAI 已知签名证书指纹后再向 Android 提交安装请求；官方商店保持默认渠道。
- 本版本构建若加入 chatgpt-official.apk 且签名匹配，可自行完成两包均内置的分发；默认不虚构资产。

## 状态顺序
- Clash 不存在：一键校验原包并请求系统安装，完成后回到连接阶段。
- Clash 存在、VPN 未连接：打开 Clash，提示用户导入自己的配置并允许系统 VPN 授权；没有自动读取用户密码/订阅。
- VPN 存在但未验证：通过 VPN 网络发起 HTTPS 到 chatgpt.com 检查；失败不打开 ChatGPT。
- 网络验证成功而 ChatGPT 不存在：若有内置经校验 APK，则由系统安装；否则打开官方 Google Play 安装页，或允许用户手动选择受信任 ChatGPT 单 APK 文件并申请系统安装。
- 二者安装且网络验证通过：打开独立的官方 ChatGPT。

## 界面
- R2 深空蓝、电光青视觉保持。首页仍一个主要状态驱动的按钮。
- 设置页第三步包括两个入口：推荐 Google Play / 已有官方 APK 从手机选择。状态反馈始终中文。
- 不会显示“已安装两个包”或“无需确认”的假承诺；被取消/失败时可以重新选择。

## 安全和兼容
- Android minSdk26 / target35，REQUEST_INSTALL_PACKAGES，仅前台用户触发。首次安装/未知来源权限/ VPN 权限不可绕过。
- 包名与已知 OpenAI APK 签名哈希同时满足才会提交本地 ChatGPT 安装；不在软件中接受来历不明的脚本或下载链接。
- APK 文件大小限制，暂存到应用私有 cache；用 PackageInstaller.Session 写入并统一反馈。不保存用户账号、订阅或其它密码。
- Google Play 分发的分包 APK 不可用单文件选择器自动组装；保持官方下载指引，单 APK 导入失败说明原因。
- 兼容安卓 8 到 15；UI 最小触控面积 48dp，短屏可滚动。

## 验收边界
- 纯 Java 行为测试 + 清单/流程静态合约 + Gradle Android 构建及 APK 签名/内置 Clash 校验。
- 没有真机运行和官方第二 APK 时，不能宣称“离线内置两个 APK 已测试安装成功”。
