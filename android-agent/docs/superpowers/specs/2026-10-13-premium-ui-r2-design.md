# GPT 启动助手 R2.0：极简科技界面规格

## 目标
让不熟悉手机设置的客户能够在首次安装后依次完成 Clash、VPN、官方 ChatGPT，日常使用时仅面对一个明显主按钮；页面视觉具有高端科技感，而不是开发者工具或操作面板。

## 约束
- Android SDK min 26 / target 35；继续使用原生 Android Java，不引入网络依赖或客户端 WebView。
- 保持包名 `com.jeyu.clashgptstarter`、原始内置 Clash APK SHA-256、`PackageInstaller` 用户确认、官方 ChatGPT 包名与 Google Play、VPN 强制 HTTPS 探测不变。
- 不读取密码、节点数据，不宣称控制了 Clash，不在无法确认 VPN 和 HTTPS 时打开 GPT。
- 不变更签名无法保留旧版应用数据；Debug 版签名和 R1 不一定一致，升级安装需验证，无法验证时明确提示可卸载后安装。

## 信息架构
1. 首页：品牌条（左）+ 设置入口（右），科技轨道视觉，动态标题、单一高亮主按钮，三项只读状态，简洁问题提示。
2. 设置与帮助：返回首页、三步设置卡（连接工具安装/打开、在 Clash 中选择节点并连接、官方 ChatGPT 安装），末尾连接检测、隐私声明。
3. 任何失败状态给出中文具体下一步。不使用专业英文作为关键指令。

## 视觉与交互
- 设计语言：深空黑蓝背景 (#070D19)、蓝灰玻璃面板 (#142239)、冷白文字 (#F2F7FF)、青色强调 (#4BE7E1)、蓝紫点光。
- 自绘静态网格/光晕底景，自绘中枢圆环；不使用复杂大面积动画或模糊，尊重省电和无障碍。
- 各交互元素点击面积不小于 48dp；首页主按钮 >= 60dp；文字正文 >=14sp；帮助页支持纵向滚动，Android 15 WindowInsets 避让状态栏/底部导航。
- 状态与色彩同步，但颜色不是唯一信息；明确显示“未安装”“未连接”“待验证”“可使用”。
- 动态首页状态由纯 Java UiCopy 生成，Activity 只做绑定，避免 UI 与 FlowDecision 决策不一致。

## 可测试契约
- 原有 30 项测试持续通过，新增状态文案/按钮选择 12 条以上测试。
- 安全合同：VPN 存在但 HTTPS 未验证不显示“已就绪”；卸载 Clash 时不允许打开 ChatGPT；无法安装时给指引。
- 工程构建：Gradle assembleDebug，apk 验签、zipalign、embedded Clash SHA-256 对比；APK 版本 2.0.0。
- UI 审查：真机/模拟器首页和设置页截图优先；如仅有布局预览应标注未进行真机验证。
